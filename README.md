This application is built for the sole purpose of fulfilling the "BackendEngineerTechnicalAssignment.pdf", which is in the project root folder.
Because of that some aspects of the implementation are not complete.

How to run:
1. In terminal run "docker-compose up -d". This will setup your Kafka and Postgre containers.
2. In an IDE or again in a terminal run the Spring Boot application.
3. Make requests using Postman or curl
